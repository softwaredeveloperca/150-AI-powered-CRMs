## Featured GitHub repository: [IceburgCRM](https://github.com/iceburgcrm/iceburgcrm)

**Description:** IceburgCRM is an open source, metadata-driven CRM builder made with Laravel and Vue. It lets teams create or adapt CRM modules, fields, relationships, subpanels, and workflows, with role permissions, import/export, and an API. Its optional AI Builder can generate a CRM structure from a plain-language prompt. AI Assist can suggest values for empty fields and shows a preview before saving. The project can also create a CRM from an existing database. AI features require a configured model provider and may incur API charges.

[View the GitHub repository](https://github.com/iceburgcrm/iceburgcrm) · [Read the project README](https://github.com/iceburgcrm/iceburgcrm/blob/main/README.md)
